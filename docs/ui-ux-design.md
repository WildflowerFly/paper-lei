## 1. 设计目标与范围

### 1.1 核心方向

产品采用简约的黑、白、灰视觉体系，界面以文字、留白、细边框和明确的层级组织信息。默认使用浅色主题，同时支持深色和跟随系统。避免大面积彩色背景、渐变、装饰性插画、拟物效果及无功能意义的动画。

Markdown 正文参考 GitHub 仓库 README 的排版方式：清晰的标题层级、H1/H2 下划线、适中的段落间距、浅灰代码背景、带边框的表格和左侧竖线引用。“类似 GitHub”指文档排版与常见 GFM 语法呈现，不复制 GitHub 网站导航，也不承诺与 GitHub 的所有扩展语法完全一致。

遵循 PRD 的核心布局：**文件导航在最左侧，实时预览在中央左侧，源码编辑在中央右侧**。

### 1.2 V1.0 范围

覆盖本地文件管理、多标签、源码编辑、实时预览、自动保存、文件冲突、图片、代码高亮、数学公式、Mermaid、目录、搜索、阅读设置、HTML/PDF 导出和打印。基础恢复提示属于 V1.0；更完善的恢复管理、自定义快捷键和自定义主题属于后续版本。

V1.0 不设计账号、登录、云同步、协作或插件市场。本文中 PRD 未规定的具体尺寸、默认值和交互规则属于本次设计决策，按本规范实施，并通过样例与测试验证。

├────────────────┬─────────────────────────────────────────────────────────┤
│ 工作空间名称    │ README.md ×   notes.md ● ×   +                          │
│ 文件 / 搜索 / 目录├───────────────────────────┬─────────────────────────────┤
│                │ 预览                      │ 源码                        │
│ 文件树         │                           │  1  # Markdown Studio      │
│                │ Markdown Studio           │  2                         │
│                │ ───────────────────       │  3  正文内容……             │
│ 最近打开       │ 正文内容……                │                            │

文档目录采用左侧导航栏内的切换页签，与文件、搜索共用区域；这是 PRD 允许的可切换独立侧栏方案，避免默认再增加第四栏。最近打开、收藏位于“文件”页内的可折叠分组。

### 2.2 尺寸与缩放

以下尺寸均为 WebView 中的 CSS 像素，原生标题栏由 Windows 管理；应用须支持 Windows 100%、125%、150%、200% DPI 缩放。

| 元素 | 默认值 | 约束 / 行为 |
| --- | --- | --- |
| 窗口 | 1440 × 900 | 受可用屏幕工作区限制，不能打开到屏幕外 |
| 最小窗口 | 960 × 640 | 小屏或高 DPI 下按可用区域约束，采用下述窄窗降级 |
| 菜单和常用工具区 | 40 高 | 左菜单、右少量工具，溢出进入“更多” |
| 文档标签栏 | 36 高 | 单标签宽 120–220；溢出可横向滚动并提供列表 |
| 导航栏 | 240 宽 | 可拖动至 180–360，可隐藏，记忆宽度 |
| 预览 / 源码区域标题 | 32 高 | 显示区域名称与少量局部操作 |
| 中央分栏比例 | 50% / 50% | 可拖动；预览最小 320，编辑最小 320 |
| 分栏拖拽条 | 可见 1，命中区 8 | hover 增强对比；键盘方向键每次调整 16 |
| 状态栏 | 24 高 | 信息不足时优先保留保存状态、光标位置 |
| 正文最大宽度 | 860 | 居中；可设置为 640–1200 或自适应 |
| 预览内边距 | 水平 32、垂直 24 | 较窄区域水平缩至 20 |

当中央可用宽度小于 640 时，隐藏导航栏以优先保留双栏；仍不足时，临时使用当前选定的单栏模式，并显示可切换的“预览 / 源码”入口。恢复宽度后恢复用户原先的分栏偏好，临时降级不覆盖持久化设置。表格和代码可在块内横向滚动，正文区域不得产生整体水平滚动。

### 2.3 界面模式

| 模式 | 可见内容 | 默认入口 |
| --- | --- | --- |
| 双栏 | 导航、预览、源码、工具、状态栏 | 默认 |
| 仅预览 | 导航、预览、工具、状态栏 | 视图菜单 / 区域操作 |
| 仅源码 | 导航、源码、工具、状态栏 | 视图菜单 / 区域操作 |
| 专注 | 保留标签、当前文档区域与必要保存提示 | F8；可与三种文档布局组合 |
| 全屏 | Windows 窗口进入原生全屏；应用布局按当前模式 | F11；再次按下退出 |

专注模式隐藏菜单工具区、导航与一般状态栏，顶部保留低干扰退出入口；保存失败和冲突提示仍可见。全屏与专注独立，不更改文件和布局数据。

## 3. 视觉基础与设计变量

### 3.1 颜色

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg-app` | `#FFFFFF` | `#0D1117` | 文档与主体背景 |
| `--bg-panel` | `#F6F8FA` | `#161B22` | 导航、工具、代码块 |
| `--bg-hover` | `#EAEEF2` | `#21262D` | 悬停、辅助分区 |
| `--bg-selected` | `#E5E7EB` | `#30363D` | 当前文件、菜单选中 |
| `--text-primary` | `#1F2328` | `#E6EDF3` | 正文、标题 |
| `--text-secondary` | `#59636E` | `#9DA7B3` | 次级说明、行号 |
| `--text-disabled` | `#8C959F` | `#6E7681` | 不可用控件；不用于正文 |
| `--border-default` | `#D1D9E0` | `#3D444D` | 边框、分隔线 |
| `--focus-ring` | `#24292F` | `#F0F6FC` | 键盘焦点；2px 外描边 |
| `--action-bg` | `#24292F` | `#F0F6FC` | 主要按钮 |
| `--action-text` | `#FFFFFF` | `#0D1117` | 主要按钮文字 |
| `--link` | `#0969DA` | `#79C0FF` | 仅 Markdown 文档链接 |
| `--danger` | `#B42318` | `#FF938A` | 删除、失败、冲突辅助提示 |
| `--warning` | `#7A4D00` | `#EAC54F` | 少量告警文字 / 图标 |

黑白灰是应用界面的主色。文档链接允许使用接近 GitHub 的蓝色，代码高亮允许有限语法色，用户图片与图表保留内容色彩。不得将这些例外扩展为大面积界面强调色。错误必须同时使用图标和文字，不能只靠红色表达；“已保存”使用中性文字与勾形图标。

普通文本与背景对比度目标不低于 4.5:1，大字与交互边界不低于 3:1；开发时测量实际叠加后的颜色。浅色和深色的正文、焦点、选中、错误均需分别验收。

### 3.2 字体与排版

| 场景 | 默认字体栈 / 数值 |
| --- | --- |
| 界面字体 | `"Segoe UI", "Microsoft YaHei UI", sans-serif`，13px / 1.5 |
| 正文字体 | `-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans", "Microsoft YaHei", sans-serif`，16px / 1.5 |
| 标题字体 | 默认继承正文，可在阅读设置中独立选择 |
| 代码与源码 | `"Cascadia Code", Consolas, "Liberation Mono", monospace` |
| 编辑器 | 14px，行高 1.6，制表符宽 2，默认自动换行 |
| Markdown 代码块 | 13.6px，行高 1.45 |
| 标签 / 状态栏 | 12px / 1.4 |

不依赖远程字体。设置面板允许选择本机字体并即时预览；选择不存在的字体时使用后备字体。正文大小支持 12–24px，源码大小支持 12–24px，阅读行高支持 1.3–2.0，段落间距支持 8–24px。

### 3.3 间距、圆角、图标和动效

- 间距采用 4px 基础单位：4、8、12、16、24、32、48。
- 常规按钮和输入框圆角 6；菜单、弹窗圆角 8；面板主要采用直线分割。
- 工具图标为统一线性风格，16px 图形、至少 28 × 28 命中区；主要按钮高 32。
- 文档正文不包裹在悬浮卡片中；阴影只用于浮层、菜单和对话框。
- hover/focus 过渡 100–150ms；不对每次预览刷新播放动画。
- 尊重减少动态效果设置；滚动定位默认即时，显式章节导航可短距离平滑滚动。

## 4. GitHub 风格 Markdown 渲染规范

### 4.1 样式边界

所有正文样式限制在 `.markdown-body` 下，不能污染应用按钮、表单和菜单。建立仓库内固定的渲染样例与截图基线，参考 GitHub 浅色和深色文档样式，并按本节定值本地实现；如复用 `github-markdown-css`，须固定版本、保留许可证并覆盖约定的变量。

HTML 导出、PDF 导出与预览共用正文样式和同一渲染结果；PDF 使用独立打印样式处理分页。用户自定义阅读字体和宽度在预览即时生效，导出时提供“当前阅读样式 / 默认文档样式”，默认使用当前阅读样式，PDF 默认转为浅色。

### 4.2 元素规范

| 元素 | 视觉与交互要求 |
| --- | --- |
| H1 | 2em、600 字重；底部 1px 分隔线；下内边距 0.3em |
| H2 | 1.5em、600 字重；同样使用底部分隔线 |
| H3 / H4 | 1.25em / 1em、600 字重 |
| H5 / H6 | 0.875em / 0.85em、600 字重；H6 使用次级文字色 |
| 标题间距 | 上 24、下 16；首个块上间距 0；标题锚点在 hover/focus 时出现 |
| 段落 | 下间距 16；普通单换行不强制 `<br>`，遵循 Markdown 换行语义 |
| 强调 / 删除线 | 粗体 600，斜体保留原语义，删除线不降低可读性 |
| 分隔线 | 4px 中性浅灰实线，垂直间距 24 |
| 列表 | 左内边距 2em，连续项间距 4；嵌套层级与 Markdown 结构一致 |
| 任务列表 | 复选框只读，默认不通过预览修改源码；明确区分已完成与未完成 |
| 引用 | 左侧 0.25em 灰色边框，左右内边距 1em，次级文字色 |
| 行内代码 | 中性背景、6px 圆角、`0.2em 0.4em` 内边距、字号 85% |
| 代码块 | 面板背景、6px 圆角、内边距 16、独立水平滚动；保留原始空白 |
| 代码块工具 | 顶部显示语言，右上角复制按钮；成功显示“已复制”2 秒，失败给出提示 |
| 表格 | 折叠边框，单元格 1px 边框、内边距 6px 13px；表头加粗、隔行浅灰背景 |
| 宽表格 | 块内水平滚动，不压缩文字到不可读；有清晰滚动提示 |
| 链接 | 蓝色；hover/focus 下划线；键盘可访问；状态提示显示完整目标地址 |
| 图片 | `max-width: 100%`、等比缩放；不放大低分辨率图到容器全宽 |
| 脚注 | 支持文内编号、底部脚注和返回链接；点击在文档内定位 |
| 数学公式 | KaTeX 排版；行内不打乱行高；独立公式居中，过宽时块内滚动 |
| Mermaid | 默认中性配色，图表独立容器，提供查看 / 缩放入口 |
| 常见 HTML | 支持安全的表格、行内格式、`details/summary` 等；过滤后的结果不破坏应用布局 |

长 URL、连续英文和中文混排需合理换行；代码块不强制折行。代码高亮默认采用浅色 / 深色 GitHub 风格主题，可单独选择少量内置主题，不能改变应用主题。

### 4.3 特殊状态

| 状态 | 显示与处理 |
| --- | --- |
| 图片不存在或不可读 | 保留替代文本、显示“图片无法加载”和路径信息；可重试 |
| 本地图片位于未授权目录 | 显示“需要允许访问此图片”及授权入口，避免只显示破图 |
| 网络图片未允许加载 | 显示域名和“加载本次文档的网络图片”；默认不请求网络 |
| 未知代码语言 | 显示语言名与纯文本代码，复制仍可用 |
| 公式无效 | 当前公式块显示简短错误，可展开源码；其他内容继续渲染 |
| Mermaid 无效 / 超限 | 当前图表块显示原因与源码；允许修改后重试 |
| 超大文档降级 | 非阻塞提示“已减少高亮和图表渲染以保持编辑流畅” |
| 原始 HTML 含危险内容 | 移除危险节点和属性；文档级轻量提示可查看被阻止类型，不执行内容 |

## 5. 核心组件规范

### 5.1 菜单与工具区

| 菜单 | V1.0 主要操作 |
| --- | --- |
| 文件 | 新建、打开文件、打开文件夹、最近打开、保存、全部保存、另存为、导出、打印、关闭标签、退出 |
| 编辑 | 撤销、重做、剪切、复制、粘贴、全选、查找、替换 |
| 视图 | 双栏 / 仅预览 / 仅源码、导航、目录、滚动同步、主题、专注、全屏 |
| 格式 | 标题、粗体、斜体、删除线、列表、引用、代码、链接、图片、表格 |
| 工具 | 工作空间搜索、快速打开、复制 Markdown、复制渲染 HTML、设置 |
| 帮助 | 快捷键说明、关于、版本与开源许可证 |

使用 Windows 原生标题栏，菜单和命令统一由应用命令注册表驱动。无活动文档时保存、导出等不可用；只读或冲突文档显示原因。快捷键提示跟随命令定义，菜单与工具按钮不能有不同的执行逻辑。

### 5.2 文件导航

- 文件、搜索、目录三个页签可通过鼠标和键盘切换，页签图标配文字或无障碍名称。
- 文件夹在前，文件在后，按自然排序排列；默认展示 Markdown 文件和目录，不作为完整磁盘浏览器。
- 文件夹展开时按需加载；空文件夹仍可显示以支持新建。
- 当前文件使用灰色选中底，键盘焦点另用描边表达。
- 悬停显示路径；长名称省略，完整名称可通过提示和无障碍名称访问。
- 右键提供新建文件、新建文件夹、重命名、删除、收藏、在资源管理器中显示。
- 重命名使用行内输入，Enter 提交、Esc 取消；名称重复或非法时保留输入并就地提示。
- 文件夹删除对话框显示位置、文件/文件夹数量和“移至回收站”；统计未完成时显示“正在统计”，不能伪造数量。
- 最近打开和收藏的失效路径显示“文件不存在”，提供重新定位或移除记录。

### 5.3 标签与状态栏

标签显示文件名、未保存圆点和关闭按钮；同名文件附加最短可区分的父目录，完整路径在提示中展示。点击已打开文件复用标签，不重复打开。切换标签保留各文档光标、选区、滚动和撤销历史。

状态栏始终准确区分：`未保存`、`等待保存`、`正在保存…`、`已保存`、`保存失败`、`文件冲突`、`只读`。未命名文档显示“未命名 1”，首次保存前不能显示“已保存”。

字数以中文单字和其他语言词项的组合口径统计；字符数按 Unicode 码点计数，包含空白与换行。状态提示说明统计基于 Markdown 源码，行/列从 1 开始；具体算法与技术文档一致。保存状态通过礼貌级无障碍通知播报，避免每次敲键重复播报。

### 5.4 按钮、浮层和设置

- 主按钮使用黑底白字或深色主题下的反相样式；同一对话框最多一个主要按钮。
- 次按钮为细边框或文字按钮；危险操作使用明确动词，不以“确定”代替“移至回收站”。
- 弹窗设置焦点陷阱，Esc 取消，关闭后焦点回到触发位置；不可逆选择默认不聚焦危险按钮。
- 轻提示用于复制成功等短反馈；保存失败、冲突、恢复提示必须可持续查看，不能只用自动消失提示。
- 设置分为外观、编辑器、阅读、文件与保存、资源加载五组，修改即时应用；提供分组恢复默认。
- 预览字体、源码字体、行号、折行、制表符宽、当前行高亮、代码主题、布局宽度都在 V1.0 可配置。

## 6. 关键用户流程

### 6.1 启动、打开与空状态

首次启动展示简洁欢迎页：打开文件、打开文件夹、新建文档及最近打开。没有工作空间时，导航区说明“打开文件夹以管理文档”，仍允许单文件编辑。

打开 `.md` / `.markdown`、系统关联和窗口拖放进入同一打开流程。加载过程中显示文件名与进度状态；成功后同时展示预览与源码；失败说明路径、原因和可执行操作。非 UTF-8 文件不能被错误解码后自动覆盖，提供只读提示与使用其他工具转换编码的说明。

### 6.2 编辑与保存

```text
输入 → 显示未保存 → 预览更新 → 停止输入 800ms → 保存中 → 已保存
                                             ├─ 失败：保留文本、显示重试 / 另存为
                                             └─ 外部变化：暂停保存、进入冲突处理
```

未命名文档持续保留草稿，Ctrl+S 选择文件路径后才能对原文件启用自动保存。关闭有未保存内容的标签时提供“保存”“不保存”“取消”；关闭应用时列出涉及的所有文档，提供“全部保存”“全部不保存”“取消”。保存失败时仍保留窗口和内容。

### 6.3 外部修改与恢复

- 当前文档无本地改动：提示“文件已在外部更新”，安全重新加载并尽可能恢复阅读位置；不能把加载动作当作用户编辑加入脏状态。
- 存在本地改动、待保存或保存中：显示持续冲突横幅，暂停自动保存，提供“查看差异”“重新加载磁盘版本”“保留当前编辑”。
- “保留当前编辑”仅保留内存内容并继续暂停覆盖，不能代表已授权覆盖磁盘；用户可另存副本，或在查看最新磁盘版本后明确选择“覆盖磁盘版本”。磁盘再次变化则重新确认。
- “重新加载磁盘版本”会丢弃本地编辑时，先确认并保留恢复快照。
- 外部删除或重命名：显示原路径不可用，提供重新定位或另存为，不自动在原路径重建文件。
- 启动发现恢复草稿：展示文件名、原路径和恢复时间，允许恢复为独立草稿、查看差异或放弃；不静默覆盖原文件。

### 6.4 预览定位与滚动同步

普通预览段落点击将右侧源码定位到对应块，短暂突出对应行；复杂节点定位到最近的可靠块起始行。鼠标拖动选中文字不触发跳转。链接、复制按钮、图片查看、折叠 HTML 等互动元素执行自身操作，不触发源码跳转。

标题锚点、脚注和目录使用文档内导航。任务复选框只读，点击可定位对应源码。滚动同步默认开启，可在视图菜单关闭；以段落和标题位置映射，不能只按滚动百分比。触控板、鼠标拖动滚动条和快速反向滚动都不应来回抢夺滚动位置。

### 6.5 搜索与快速打开

当前文档查找浮层位于源码区域顶部，显示输入框、命中数量、前一个、后一个与关闭；Ctrl+H 展开替换。仅预览模式调用替换时先展示源码。无结果明确显示“无匹配结果”，不能只留空。

全局搜索位于左侧“搜索”页，支持文件名 / 内容切换；结果按文件分组，显示路径、行号和命中摘要。点击结果打开或切换标签并定位。搜索可取消，正在加载、结果被截断、权限错误分别提示。快速打开采用居中轻量浮层，输入文件名后可用上下键选择、Enter 打开、Esc 退出。

### 6.6 图片插入与查看

拖入 Markdown 文件进入打开流程；拖入图片到编辑器进入图片插入流程。首次插入询问“引用原路径”或“复制到资源目录并引用”，可记忆偏好，默认建议复制到文档旁的 `assets/`。未命名文档先选择保存位置，取消则不写入资源文件。

复制资源重名时自动生成不冲突名称，成功后再插入 Markdown；不移动、不删除原图。引用跨目录图片需显示可移植性说明。大图查看浮层支持缩放、适应窗口、原始尺寸，Esc 关闭并恢复焦点。

### 6.7 导出和打印

导出对话框选择格式、保存路径、阅读样式和资源打包方式。HTML 默认将已授权的可用图片嵌入单文件，超出资源预算时提供配套资源目录；PDF 默认 A4、纵向、页边距 16mm，可选 Letter 和横向。

显示准备渲染、处理资源、生成文件的状态；失败可重试且不修改 Markdown 原文件。缺失图片或被阻止的网络资源列入确认信息，可返回处理或明确继续导出占位内容。不把未渲染完的图表、字体加载中的公式作为成功结果。打印调用 Windows 打印入口，取消打印属于正常取消。

## 7. 键盘与无障碍

### 7.1 默认快捷键

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 新建 / 打开 / 保存 | Ctrl+N / Ctrl+O / Ctrl+S | 遵循 PRD |
| 全部保存 | Ctrl+Shift+S | 不用于另存为；另存为通过文件菜单 |
| 打开文件夹 | Ctrl+Alt+O | 新增约定 |
| 查找 / 替换 | Ctrl+F / Ctrl+H | 当前文档 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y | 当前文档独立历史 |
| 切换导航栏 | Ctrl+B | 保留 PRD 约定；不得同时绑定粗体 |
| 全局搜索 / 快速打开 | Ctrl+Shift+F / Ctrl+P | Ctrl+P 留给快速打开 |
| 打印 | Ctrl+Shift+P | 通过命令层处理浏览器默认行为 |
| 专注 / 全屏 | F8 / F11 | 独立开关 |
| 关闭标签 | Ctrl+W | 有修改先确认 |
| 切换标签 | Ctrl+Tab / Ctrl+Shift+Tab | 按标签顺序 |
| 在主要区域间移动 | F6 / Shift+F6 | 导航、预览、编辑器、状态操作 |
| 关闭浮层 / 取消 | Esc | 优先关闭最上层浮层 |

粗体等格式操作通过菜单和工具入口提供，V1.0 不额外分配与输入法冲突的组合。V1.1 再支持快捷键自定义。菜单助记键和编辑器默认快捷键必须统一排查，中文输入法组合期间不得执行会中断输入的命令。

### 7.2 可访问性

- Tab 顺序与视觉顺序一致；树、标签和菜单遵循对应 ARIA 键盘模式。
- 所有纯图标按钮具备可读名称；工具提示不能作为唯一名称来源。
- 拖拽分隔条具有 separator 角色和当前值，支持键盘调整。
- 编辑器中使用 Tab 缩进时，提供并说明 Esc 后 Tab 的焦点退出方式，避免键盘陷阱。
- 阅读区为独立可聚焦 region，公式保留可读语义，图片使用 alt，图表提供源码或说明。
- 浮层和错误提示不能挡住关闭、取消、保存等关键入口。
- 用 Windows Narrator 检查打开、编辑、保存失败、搜索、冲突处理和关闭流程。
