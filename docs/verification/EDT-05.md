# EDT-05 双向滚动同步与锚点保持验收

关联 PRD §5.2、UX-07。验证环境为本机 Windows，使用 Playwright 自带的 Chromium，截图视窗为 1050 × 780 CSS 像素。

- 双栏通过顶层内容块的行范围和实测高度进行查找及局部插值。滚动事件按动画帧合并，由实际写入的位置识别被动事件。短文档按可滚动范围截断。
- 视图菜单提供默认开启的滚动同步复选项，开关在重启后保留。单栏和关闭同步时可独立滚动。
- 预览持续使用无脚本 iframe。内容更新和标签切换时按内容指纹恢复阅读块。图片加载、字体就绪和布局变化时重新测量。

## 执行与结果

运行 `pnpm exec playwright test tests/e2e/scroll-sync.spec.ts --workers=4`，四项通过。覆盖两种长度下的双向定位与反向滚动、分栏变化、异步图片布局、编辑与标签切换后的锚点恢复、主题和开关设置。图片测试通过在隔离预览内插入合成图片验证布局变化。正式路径授权与加载由 RES-01 验收，公式和图表混排实测由 RES-03 和 QUAL-03 继续覆盖。
