# FND-03 Windows 文件事务风险验证

时间：2026-11-18。环境同 FND-01，Windows 11、固定本地 NTFS 卷。仅使用随机临时目录与合成文本，不对用户文档执行测试。通过 `git log --grep=FND-03` 找实现提交。

## 复现

```powershell
cargo test --locked --manifest-path src-tauri/Cargo.toml --test safe_save
pnpm check
```

原型位于 `src-tauri/src/prototypes/safe_save.rs`，无 IPC，可在不启动 WebView 的情况下实测。15 个原生测试入口通过（其中一个是进程终止测试助手）。

| 注入/场景                  | 实测结果                                                                                                    |
| -------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 正常替换、中文路径         | 核对目标、编辑快照、实际被替换的备份及基线字节；替换前后 Windows ACL 的 SDDL 相同                           |
| 复核前外部写入             | 返回 `CONFLICT`，目标保留外部字节，事务目录保留 local/base                                                  |
| 最后一次复核后外部写入     | `ReplaceFileW` 备份反映实际被替换版本；返回 `CONFLICT_DURING_COMMIT`，保留 base/local/disk，不静默回滚      |
| 复核后外部原子替换         | 即使内容完全相同，文件 ID 改变仍报提交冲突                                                                  |
| 提交后外部写入             | 提交后核验发现差异，不误报保存成功，保留最新外部内容                                                        |
| 外部删除、新建同名目标抢占 | 不自动重建旧路径；新建使用无覆盖提交，不覆盖第三方文件                                                      |
| 文件占用、模拟满盘         | 排他句柄抑制写入；候选写到一半注入 Windows 错误 112，原件和完整编辑快照不受影响                             |
| 进程终止                   | 子进程在替换前/后直接退出，父进程重新枚举事务记录、验证 base/local 及替换前原件或替换后 disk 备份           |
| 回收站                     | Shell 将合成文件移入回收站，按其精确原路径查回并恢复，字节一致；注入回收失败时目标完整，代码不降级为 unlink |

## 结论与限制

R-02 的原型可行性在本机通过。仅支持已验证的本地固定 NTFS；其他卷、重解析点不作为可写基线。进程终止不等同断电；写入失败使用故障注入而非填满用户磁盘。原型只针对受控测试目录，不是面向任意路径的安全 API，不开放给渲染器。

事务目录保留唯一名称的 `base.md`、`local.md`、`disk.md`（已替换时）与 `recovery.json`。原型不提供自动清理或自动恢复，以免删除尚未处理的冲突。正式功能需由 FILE-01/03/04/08 实现授权、串行化、冲突展示和恢复生命周期；在这些任务完成前不要启用自动保存。
