## 专项验收

- 设置面板选择浅色/深色/跟随系统立即更新 `data-theme`；重载后主题和默认布局仍保持。
- 工具栏主题命令按系统 → 浅色 → 深色 → 系统循环，不改变文档内容。
- 写入无效 JSON 或未知 schema 时应用正常启动；设置面板显示“配置文件无法读取，已恢复默认设置”，并生成带时间戳的损坏备份。
- 窗口恢复函数要求至少 48×48 像素可见交集；无交集时移动并裁剪到当前显示器工作区，保证移除外接显示器后窗口可见。
