# UI-04 导航、标签与空状态框架验收

任务 ID / 验收编号：UI-04 / PRD §3、§4.1  
验收日期：2026-11-19  
执行人：Codex

## 实现范围

- 文件、搜索、目录三个导航页签共用左侧区域，支持 Arrow/Home/End 键盘切换并保持正确焦点。
- 文件页显示文件树演示数据、重复文件名的最短区分路径、最近打开、收藏和失效路径状态。
- 标签点击/键盘切换、关闭入口、已打开文件复用和全部关闭后的欢迎空状态。
- 搜索页空结果与目录页空/有标题状态；演示数据与后续文件服务保持分离。

## 执行命令与结果

```powershell
pnpm lint
pnpm typecheck
$env:UI_EVIDENCE='1'; $env:UI_THEME='light'
pnpm exec playwright test tests/e2e/navigation.spec.ts
$env:UI_THEME='dark'
pnpm exec playwright test tests/e2e/navigation.spec.ts --grep "keyboard navigation"
```

结果：通过。导航专项 3 项测试全部通过，浅色/深色截图均已生成。

- 导航页签键盘 ArrowRight、End、Home 切换并将焦点移动到对应页签。
- 同名 `README.md` 显示 `docs/README.md` / `examples/README.md` 区分路径；最近打开和收藏分组可见。
- `archive.md` 失效记录显示“文件不存在”，点击后通过持续状态反馈重新定位/移除提示入口。
- 点击已打开文件不重复创建标签；关闭全部标签后显示欢迎页、新建文档和打开文件入口。
- 目录和搜索的空状态均有明确文本，不依赖控制台或空白区域猜测。
