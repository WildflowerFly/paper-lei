## 环境

- Windows 11；Node.js 22；pnpm 11.25.0；Playwright Chromium。
- 应用主题变量使用本地 CSS，不依赖网络字体或远程资源。

## 实现范围

- `src/styles/tokens.css`：黑白灰浅色/深色 token、系统主题回退和交互边界颜色。
- `src/styles/controls.css`：按钮、输入框、菜单、Tooltip、对话框、轻提示和持续错误条。
- `src/components/ui/`：可访问的基础 Vue 组件，统一处理 ARIA、键盘和焦点行为。
- `tests/e2e/controls.spec.ts`：主题对比度及控件键盘行为回归。

## 执行命令与结果

```powershell
. ./.tmp/toolchain.ps1
$env:UI_EVIDENCE='1'
pnpm check
```

结果：通过。格式检查、ESLint、TypeScript、Vitest（10 tests）、Rust fmt/clippy/test、生产构建和 Playwright（7 tests）全部通过。

控件专项测试：

- 对话框打开后焦点进入取消按钮；Tab/Shift+Tab 在对话框内循环；Escape 关闭并将焦点返回触发按钮。
- 菜单支持 ArrowUp/ArrowDown、Home、End、Escape；禁用菜单项不可执行，选择后状态反馈可见。
- Tooltip 在键盘焦点下可见，Escape 可关闭；字段错误通过 `aria-invalid` 与可访问描述关联。
- 持续错误条同时提供图标、文本和关闭操作，避免仅依赖颜色表达错误。
- 浅色和深色主题均满足：正文对比度 ≥ 4.5:1、主要按钮文字 ≥ 4.5:1、焦点环和控件边界 ≥ 3:1。
