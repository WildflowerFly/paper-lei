# UI-02 主窗口、分栏与窄窗适配验收

任务 ID / 验收编号：UI-02 / UX-01、UX-05、UX-09  
验收日期：2026-11-19  
执行人：Codex

## 环境与范围

- Windows 11；Chromium Playwright；CSS 视口覆盖 1440 × 900 和 800 × 640（对应规范中的最小区域降级路径）。
- 主窗口使用 Tauri 配置的 1440 × 900 默认尺寸、960 × 640 最小原生窗口约束；WebView 内布局按 CSS 像素响应。
- 实现包含应用工具区、左侧文件/搜索/目录导航、文档标签栏、预览/源码双栏、可拖动分隔条、状态栏和窄窗切换入口。

## 执行命令与结果

```powershell
pnpm lint
pnpm typecheck
$env:UI_EVIDENCE='1'
pnpm exec playwright test tests/e2e/layout.spec.ts
```

结果：通过。3 个 UI-02 E2E 测试全部通过。

- 1440 × 900：导航、标签、预览、源码和状态栏均可见；工具区 40px、标签栏 36px、状态栏 24px。
- 分隔条使用 `separator` 角色，鼠标命中区 8px，键盘左右方向每次调整 16px，值限制在两侧至少 320px。
- 双栏 / 仅预览 / 仅源码可通过工具区入口切换；状态栏同步显示当前模式。
- 800 × 640：中央区域不足 640px 时自动隐藏导航，保留双栏偏好并显示预览/源码切换；切换源码后编辑区仍可访问。
- 导航分隔条支持 180–360px 范围和左右方向键调整；标签区保持 120–220px 单标签约束并允许横向滚动。
