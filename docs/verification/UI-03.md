# UI-03 命令注册表与菜单入口验收

验收日期：2026-11-19  
执行人：Codex

## 实现范围

- `src/services/commands.ts`：集中声明六个菜单、命令 ID、显示名称、快捷键和文档可用条件。
- `src/App.vue`：菜单、工具按钮和全局快捷键统一调用 `dispatchCommand`；保存/导出根据活动文档状态同步禁用。
- `tests/e2e/commands.spec.ts`：菜单入口、无文档禁用和跨入口一致性验收。
- `src/services/commands.test.ts`：快捷键冲突和命令可用性规则测试。

## 执行命令与结果

```powershell
pnpm lint
pnpm typecheck
pnpm test -- --run src/services/commands.test.ts
pnpm exec playwright test tests/e2e/commands.spec.ts
```

结果：通过。注册表单测 2 个测试（合计 Vitest 12 passed），命令 E2E 2 个测试全部通过。

- 文件、编辑、视图、格式、工具、帮助六个菜单由同一注册表生成。
- `Ctrl+B` 唯一绑定导航切换，`Ctrl+Shift+S` 绑定全部保存；注册表冲突检查返回空列表。
- 保存、全部保存、另存为、导出、打印和编辑/格式命令在无活动文档时禁用；工具按钮与菜单项状态一致。
- 菜单选择、工具按钮和快捷键均进入同一个分发函数；视图命令的布局、导航和主题结果一致。
- 菜单项显示注册表中的快捷键，输入法组合事件（`isComposing`）不会触发全局命令。
